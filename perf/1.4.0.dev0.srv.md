## Key Takeaways

- Rust compilation via serde bridge: **0.89x** average (serde overhead dominates at current query sizes)
- End-to-end (including dict conversion): **0.50x** average
- Validation: **9.2x** average speedup
- Serde dict conversion is the primary bottleneck for the Rust path
- Direct Rust AST construction (bypassing Python dicts) would unlock the full 5-10x speedup seen in criterion benchmarks
