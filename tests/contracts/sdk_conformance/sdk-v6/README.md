# Sdk V6 distribution authority

Sdk V6 is the additive C distribution successor. Its frozen catalog selects
exactly G05, G06, G08, G12, and G13, but it does not promote them or claim a
completed artifact. The digest-bound `c-broad-case-ledger-v1.json` freezes the
Query, data, migration, codec, and distribution evidence for G05, G06, G08, and G13. It is a prerequisite, not a
promotion: final reports and evidence schemas are added only after the final
artifacts and four clean-consumer reports exist.

Each V6 report binds one generated language surface, the same standalone CLI,
native runtime, generated C package and Artifact acceptance aggregate, its real predecessor
reports (V1–V5 for Python/Node/Rust and V2–V5 for C, which entered at V2), and
the five terminal observations. The comparator rejects
cross-binding artifact/outcome drift and permits either all five pending gaps
or the complete dedicated-profile transition; partial promotion is invalid.
The assembler accepts canonical same-run producer evidence, hashes every proof
fragment and generated surface itself, reconstructs the Artifact acceptance report from
the artifact archives, and requires all artifacts to name the producer's
exact source commit.

The catalog grants no release, publication, registry, tag, or public-support
authority. C remains internal, unpublished, and unsupported while #189 awaits
an explicit release-contract decision and authorization.
